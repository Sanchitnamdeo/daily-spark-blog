# ⚡ Daily Spark – Full-Stack MERN Blogging Platform

A feature-rich, modern full-stack blogging web application built with the **MERN** stack (MongoDB, Express.js, React, Node.js), featuring secure JWT authentication, RESTful APIs, responsive CSS styling, and interactive comments.

---

## 🚀 Key Features

* **Secure Authentication:** User registration and login powered by JSON Web Tokens (JWT) and bcrypt password hashing.
* **Dynamic Content Management:** Authenticated users can create, read, and delete their own blog posts.
* **Interactive Discussions:** Real-time comments section on articles allowing users to share perspectives.
* **Modern UI/UX:** Built with a sleek dark-themed interface, sliding hero banner, and category filtering.
* **RESTful Architecture:** Clean separation of concerns with structured backend controllers, routes, and Mongoose models.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, HTML5, CSS3, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Authentication:** JSON Web Tokens (JWT)
